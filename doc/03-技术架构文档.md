# 智能股票交易辅助系统 - 技术架构文档

**版本**: v0.0.1-SNAPSHOT  
**最后更新**: 2026-03-18  
**文档状态**: 已按当前实现对齐

---

## 1. 架构结论

当前版本采用：

- 前后端分离接口风格
- 单体 Spring Boot 应用
- MySQL 持久化
- Redis 缓存与 JWT 黑名单
- 东方财富 HTTP 接口作为行情来源

当前不是微服务架构，没有 Kafka、MinIO、AI 服务或 WebSocket 服务落地。

---

## 2. 当前实际架构

```text
Client
  |
  v
Spring Boot API
  |- UserController / UserService
  |- MarketController / MarketService
  |- WatchlistController / WatchlistService
  |- TradeController / TradeService
  |- JwtAuthInterceptor / JwtUtil
  |- GlobalExceptionHandler
  |
  +--> MySQL
  +--> Redis
  +--> EastMoney HTTP API
```

## 4. 模块划分

## 4.1 用户模块

### 主要职责

- 注册
- 登录
- 登出
- 查询当前用户
- 更新当前用户

### 核心类

- `UserController`
- `UserService`
- `UserServiceImpl`
- `UserMapper`

## 4.2 鉴权模块

### 主要职责

- 生成 JWT
- 解析 JWT
- 拦截受保护接口
- 登出后失效 Token

### 核心类

- `JwtUtil`
- `JwtAuthInterceptor`
- `WebConfig`
- `UserContext`

### 当前实现说明

- 采用自定义拦截器，不是完整 Spring Security 认证授权体系
- 受保护接口依赖 `Authorization: Bearer <token>`

## 4.3 行情模块

### 主要职责

- 股票搜索
- 股票详情
- K 线
- 技术指标

### 核心类

- `MarketController`
- `MarketService`
- `MarketServiceImpl`
- `EastMoneyClient`

### 当前实现说明

- 行情来源为东方财富非官方 HTTP 接口
- K 线与实时行情有 Redis 缓存
- 技术指标当前支持：
  - `MACD`
  - `KDJ`
  - `RSI`
- 指标计算已统一为 `BigDecimal` 输出

### 未实现

- 分时图
- `BOLL`
- `MA`
- 实时 WebSocket 推送

## 4.4 自选股模块

### 主要职责

- 查询
- 添加
- 删除

### 核心类

- `WatchlistController`
- `WatchlistService`
- `WatchlistServiceImpl`
- `UserWatchlistMapper`

## 4.5 模拟交易模块

### 主要职责

- 买入
- 卖出
- 持仓查询
- 账户汇总
- 交易记录

### 核心类

- `TradeController`
- `TradeService`
- `TradeServiceImpl`
- `AccountMapper`
- `TradeOrderMapper`
- `PositionMapper`
- `TradeRecordMapper`

### 当前实现说明

- 模拟撮合为同步成交
- 买卖完成后会立刻刷新账户资产和收益
- 收益率保留 4 位小数
- 交易记录支持分页和时间范围查询

### 未实现

- 撤单
- 挂单撮合
- 交易时段校验
- 更完整的市场规则

## 5. 数据流

## 5.1 登录鉴权流

```text
登录请求
  -> UserServiceImpl 校验邮箱/密码
  -> JwtUtil 生成 token
  -> 返回 token

后续请求
  -> JwtAuthInterceptor 解析 token
  -> UserContext 写入 userId
  -> Controller 执行业务
```

## 5.2 行情查询流

```text
市场请求
  -> MarketController 参数校验
  -> MarketServiceImpl
  -> EastMoneyClient
  -> 先查 Redis
  -> 未命中则调用东方财富
  -> 返回结果
```

## 5.3 模拟交易流

```text
买入/卖出请求
  -> TradeController 参数校验
  -> TradeServiceImpl
  -> 校验账户/持仓/价格
  -> 写订单
  -> 写交易记录
  -> 更新持仓
  -> 刷新账户汇总
  -> 返回成交结果
```

## 6. 配置结构

当前配置文件：`src/main/resources/application.yml`

主要配置项：

- `spring.datasource.*`
- `spring.data.redis.*`
- `server.port`
- `eastmoney.*`
- `jwt.secret`
- `jwt.expiration-seconds`

当前支持使用环境变量覆盖，但还没有 `dev/test/prod` 多配置文件体系。

## 8. 当前架构边界

当前仓库适合描述为：

- 单体后端 MVP
- 面向开发和联调的 API 服务
- 行情 + 自选股 + 模拟交易

不适合描述为：

- 生产级多服务平台
- AI 驱动股票分析系统完整体
- 回测平台

# 智能股票交易辅助系统 - 技术架构文档

**版本**: v0.0.1-SNAPSHOT  
**最后更新**: 2026-04-26  
**文档状态**: 已按当前实现对齐

---

## 1. 架构结论

当前版本采用：

- 前后端分离接口风格
- 单体 Spring Boot 应用
- MySQL 持久化
- Redis 缓存与 JWT 黑名单
- 东方财富 HTTP 接口作为行情来源
- 外部 Python 分析服务作为 AI 分析来源
- Vue 3 前端作为用户界面
- WebSocket 行情快照订阅
- 轻量风险预警和轻量回测模块

当前不是微服务架构，但已经存在一个通过 HTTP 集成的外部 AI 分析服务；Kafka、MinIO、LangChain4j 仍未落地。

## 4. 模块划分

## 4.1 用户模块

### 主要职责

- 注册
- 登录
- 登出
- 查询当前用户
- 更新当前用户

### 核心类

- `UserController`
- `UserService`
- `UserServiceImpl`
- `UserMapper`

## 4.2 鉴权模块

### 主要职责

- 生成 JWT
- 解析 JWT
- 拦截受保护接口
- 登出后失效 Token

### 核心类

- `JwtUtil`
- `JwtAuthInterceptor`
- `WebConfig`
- `UserContext`

### 当前实现说明

- 采用自定义拦截器，不是完整 Spring Security 认证授权体系
- 受保护接口依赖 `Authorization: Bearer <token>`

## 4.3 行情模块

### 主要职责

- 股票搜索
- 股票详情
- K 线
- 技术指标

### 核心类

- `MarketController`
- `MarketService`
- `MarketServiceImpl`
- `EastMoneyClient`

### 当前实现说明

- 行情来源为东方财富非官方 HTTP 接口
- K 线与实时行情有 Redis 缓存
- 技术指标当前支持：
  - `MACD`
  - `KDJ`
  - `RSI`
  - `MA`
  - `BOLL`
- 指标计算已统一为 `BigDecimal` 输出
- 支持多指标逗号组合查询
- `MarketWebSocketHandler` 支持客户端发送股票代码后立即返回快照，并每 5 秒推送一次

### 未实现

- 分时图
- 盘口五档明细
- 资金流向明细

## 4.4 自选股模块

### 主要职责

- 查询
- 添加
- 删除

### 核心类

- `WatchlistController`
- `WatchlistService`
- `WatchlistServiceImpl`
- `UserWatchlistMapper`

## 4.5 AI 分析模块

### 主要职责

- 调用外部分析服务
- 生成股票分析报告
- 保存分析历史
- 提供情绪摘要
- 提供风险摘要
- 结合分析上下文执行 AI 问答
- 保存问答历史

### 核心类

- `AnalysisController`
- `AnalysisService`
- `AnalysisServiceImpl`
- `AiAnalysis`
- `AiAnalysisMapper`
- `AnalysisServiceProperties`
- `QaController`
- `QaService`
- `QaServiceImpl`
- `QaHistory`
- `QaHistoryMapper`
- `GeminiProperties`

### 当前实现说明

- Java 主应用通过 `WebClient` 调用外部分析服务
- Java 主应用通过 Gemini API 执行 AI 问答
- 分析服务当前部署为独立 Docker 容器
- 分析结果会写入 `ai_analysis` 表
- 问答结果会写入 `qa_history` 表
- 情绪摘要和风险摘要优先复用最近一次分析结果
- AI 问答会复用最近一次股票分析作为上下文

## 4.6 交易、风险与回测模块

### 主要职责

- 模拟账户、买入、卖出、限价挂单、撤单、订单列表、持仓、交易记录
- 根据账户与持仓实时计算轻量风险预警
- 基于 K 线运行买入持有轻量回测

### 核心类

- `TradeController`
- `TradeService`
- `TradeServiceImpl`
- `RiskController`
- `RiskService`
- `RiskServiceImpl`
- `BacktestController`
- `BacktestService`
- `BacktestServiceImpl`

### 当前实现说明

- 模拟交易支持轻量限价挂单：未触价买单冻结资金，未触价卖单冻结可用持仓；撤单释放冻结资源，已成交订单不可撤销
- 风险预警不落库，根据账户现金、总资产、持仓盈亏实时生成
- 回测不落库，返回一次性买入持有测算结果

## 5. 数据流

## 5.1 登录鉴权流

```text
登录请求
  -> UserServiceImpl 校验邮箱/密码
  -> JwtUtil 生成 token
  -> 返回 token

后续请求
  -> JwtAuthInterceptor 解析 token
  -> UserContext 写入 userId
  -> Controller 执行业务
```

## 5.2 行情查询流

```text
市场请求
  -> MarketController 参数校验
  -> MarketServiceImpl
  -> EastMoneyClient
  -> 先查 Redis
  -> 未命中则调用东方财富
  -> 返回结果
```

## 5.3 AI 分析流

```text
分析请求
  -> AnalysisController
  -> AnalysisServiceImpl
  -> WebClient 调用外部分析服务
  -> 返回分析结果
  -> 写入 ai_analysis
  -> 历史/情绪/风险接口复用落库结果
```

## 5.4 AI 问答流

```text
问答请求
  -> QaController
  -> QaServiceImpl
  -> 读取最近一次股票分析
  -> WebClient 调用 Gemini API
 -> 写入 qa_history
 -> 返回问答结果
```

## 5.5 WebSocket 行情流

```text
客户端连接 /ws/market
  -> 发送 stockCode
  -> MarketWebSocketHandler 查询 MarketService
  -> 立即返回股票详情
  -> 每 5 秒继续推送该股票最新快照
```

## 8. 当前架构边界

当前仓库适合描述为：

- 单体后端 MVP
- 面向开发和联调的前后端演示系统
- 行情 + AI 分析 + 自选股 + 模拟交易 + 风险/回测闭环

不适合描述为：

- 生产级多服务平台
- 完整 AI 投顾平台
- 完整量化回测平台
- 真实交易系统

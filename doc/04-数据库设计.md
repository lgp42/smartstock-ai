## 2. 当前运行依赖表

以下表与当前代码直接对应：

| 表名 | 当前是否使用 | 说明 |
|------|--------------|------|
| `users` | 是 | 用户表 |
| `accounts` | 是 | 模拟账户表 |
| `stock_info` | 是 | 股票基础信息 |
| `news` | 是 | 新闻快讯与新闻聚合 |
| `user_watchlist` | 是 | 自选股 |
| `orders` | 是 | 订单表 |
| `positions` | 是 | 持仓表 |
| `trade_records` | 是 | 交易记录表 |

## 2.1 users

用途：

- 注册用户
- 登录校验
- 当前用户信息

关键字段：

- `email`
- `password`
- `nickname`
- `avatar`
- `status`
- `deleted`

说明：

- 当前登录方式只有邮箱
- 代码使用逻辑删除字段 `deleted`

## 2.2 accounts

用途：

- 存储模拟账户资产

关键字段：

- `total_assets`
- `available_cash`
- `frozen_cash`
- `position_value`
- `total_profit`
- `profit_rate`

说明：

- 注册后默认初始资金为 100 万

## 2.3 stock_info

用途：

- 存储股票基础信息

关键字段：

- `stock_code`
- `stock_name`
- `market`
- `board`
- `industry`
- `is_st`
- `is_delisted`
- `source`

说明：

- 行情搜索会优先查本地 `stock_info`
- 若本地未命中，再调用东方财富搜索接口
- 智能选股、股票详情回查、新闻关联都会回填 `stock_info`
- `board` 当前使用 `SH_MAIN / SZ_MAIN / CYB / STAR`

## 2.4 news

用途：

- 存储多源新闻快讯
- 支持来源筛选、关键词筛选、按股票代码筛选
- 支持新闻与股票关联

关键字段：

- `title`
- `content`
- `source`
- `url`
- `stock_code`
- `publish_time`

说明：

- 当前来源包括新浪财经、财联社、东方财富
- 当前做了轻量去重和历史落库
- 历史脏数据中的 ETF/基金代码已清洗为 `NULL`

## 2.5 user_watchlist

用途：

- 存储用户自选股

关键字段：

- `user_id`
- `stock_code`
- `sort_order`

说明：

- 当前支持查、增、删
- 当前没有排序接口

## 2.6 orders

用途：

- 存储模拟买卖订单

关键字段：

- `order_type`
- `price`
- `quantity`
- `amount`
- `fee`
- `status`
- `filled_price`
- `filled_quantity`
- `filled_time`

说明：

- 当前实现主要使用 `filled` 成交状态
- 没有撤单能力

## 2.7 positions

用途：

- 存储用户持仓

关键字段：

- `quantity`
- `available_quantity`
- `cost_price`
- `current_price`
- `market_value`
- `profit`
- `profit_rate`

说明：

- 持仓收益率当前保留 4 位小数

## 2.8 trade_records

用途：

- 存储成交记录

关键字段：

- `order_id`
- `trade_type`
- `price`
- `quantity`
- `amount`
- `fee`
- `trade_time`

说明：

- 当前支持按交易类型和时间范围分页查询

## 5. 精度说明

当前数据库设计与代码实现约定：

- 金额字段：`DECIMAL(18, 2)`
- 收益率字段：`DECIMAL(10, 4)`
- 下单价格：最多 2 位小数

---

## 6. 当前数据库边界

当前数据库设计可以支持：

- 用户体系
- 行情基础信息
- 自选股
- 模拟交易

当前数据库设计还不能说明以下功能已经可用：

- AI 分析
- 回测
- 风险预警
- 新闻系统

---

## 7. 初始化建议

当前推荐初始化方式：

```bash
mysql -u root -p -e "CREATE DATABASE smartstock_ai DEFAULT CHARACTER SET utf8mb4;"
mysql -u root -p smartstock_ai < doc/sql/init.sql
```

如果只关注当前后端 MVP，可优先确保以下表存在且数据正常：

- `users`
- `accounts`
- `stock_info`
- `user_watchlist`
- `orders`
- `positions`
- `trade_records`

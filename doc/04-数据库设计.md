## 2. 当前运行依赖表

以下表与当前代码直接对应：

| 表名 | 当前是否使用 | 说明 |
|------|--------------|------|
| `users` | 是 | 用户表 |
| `stock_info` | 是 | 股票基础信息 |
| `news` | 是 | 新闻快讯与新闻聚合 |
| `ai_analysis` | 是 | AI 分析结果 |
| `qa_history` | 是 | AI 问答历史 |
| `user_watchlist` | 是 | 自选股 |
| `accounts` | 是 | 模拟交易账户 |

| `positions` | 是 | 模拟持仓 |
| `trade_records` | 是 | 模拟交易记录 |

## 2.1 users

用途：

- 注册用户
- 登录校验
- 当前用户信息

关键字段：

- `email`
- `password`
- `nickname`
- `avatar`
- `status`
- `deleted`

说明：

- 当前登录方式只有邮箱
- 代码使用逻辑删除字段 `deleted`

## 2.2 stock_info

用途：

- 存储股票基础信息

关键字段：

- `stock_code`
- `stock_name`
- `market`
- `board`
- `industry`
- `is_st`
- `is_delisted`
- `source`

说明：

- 行情搜索会优先查本地 `stock_info`
- 若本地未命中，再调用东方财富搜索接口
- 智能选股、股票详情回查、新闻关联都会回填 `stock_info`
- `board` 当前使用 `SH_MAIN / SZ_MAIN / CYB / STAR`

## 2.3 news

用途：

- 存储多源新闻快讯
- 支持来源筛选、关键词筛选、按股票代码筛选
- 支持新闻与股票关联

关键字段：

- `title`
- `content`
- `source`
- `url`
- `stock_code`
- `publish_time`

说明：

- 当前来源包括新浪财经、财联社、东方财富
- 当前做了轻量去重和历史落库
- 历史脏数据中的 ETF/基金代码已清洗为 `NULL`

## 2.4 user_watchlist

用途：

- 存储用户自选股

关键字段：

- `user_id`
- `stock_code`
- `sort_order`

说明：

- 当前支持查、增、删
- 当前支持批量添加、批量删除、排序

## 2.5 ai_analysis

用途：

- 存储用户股票分析结果
- 为历史、情绪摘要、风险摘要、AI 问答提供上下文

关键字段：

- `user_id`
- `stock_code`
- `analysis_type`
- `input_data`
- `output_text`
- `created_at`

## 2.6 qa_history

用途：

- 存储用户问答记录

关键字段：

- `user_id`
- `question`
- `answer`
- `created_at`

## 2.7 accounts / orders / positions / trade_records

用途：

- 支持演示级模拟交易账户、订单、持仓和交易流水
- 为风险预警提供账户与持仓输入

说明：

- 当前支持轻量限价挂单：未触价买单冻结资金，未触价卖单冻结可用持仓
- 撤单接口只处理待成交状态，撤单会释放冻结资金或持仓，已成交订单不能撤销

## 5. 精度说明

当前数据库设计与代码实现约定：

- 金额字段：`DECIMAL(18, 2)`
- 收益率字段：`DECIMAL(10, 4)`
- 下单价格：最多 2 位小数

---

## 6. 当前数据库边界

当前数据库设计可以支持：

- 用户体系
- 行情基础信息
- AI 分析
- AI 问答
- 自选股
- 模拟交易
- 轻量风险预警输入数据

当前数据库设计还不能说明以下功能已经可用：

- 持久化回测报告
- 后台主动推送风险告警

## 7. 初始化建议

当前推荐初始化方式：

```bash
mysql -u root -p -e "CREATE DATABASE smartstock_ai DEFAULT CHARACTER SET utf8mb4;"
mysql -u root -p smartstock_ai < doc/sql/init.sql
```

如果只关注当前后端 MVP，可优先确保以下表存在且数据正常：

- `users`
- `stock_info`
- `user_watchlist`
- `ai_analysis`
- `qa_history`
- `accounts`
- `orders`
- `positions`
- `trade_records`

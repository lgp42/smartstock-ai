# 智能股票交易辅助系统 - 项目概述

**版本**: v0.0.1-SNAPSHOT  
**最后更新**: 2026-03-18  
**文档状态**: 已按当前代码实现对齐

---

## 1. 项目定位

`smartstock-ai` 当前是一个单体 Spring Boot 后端项目，面向个人投资者提供：

- 股票行情查询
- 自选股管理
- 模拟交易
- JWT 登录鉴权

它现在更准确的定位是“股票行情与模拟交易后端 MVP”，不是完整的 AI 投资平台。

---

## 2. 当前已实现能力

### 2.1 用户与鉴权

- 邮箱注册
- 邮箱密码登录
- JWT Token 下发
- 登出后 Token 黑名单失效
- 获取当前用户信息
- 修改昵称、头像

### 2.2 行情

- 股票搜索
- 股票详情
- 日 K、周 K、月 K、30 分钟、60 分钟 K 线
- 技术指标：
  - `MACD`
  - `KDJ`
  - `RSI`
- 东方财富行情接口接入
- Redis 缓存行情数据

### 2.3 自选股

- 查询自选股列表
- 添加自选股
- 删除自选股

### 2.4 模拟交易

- 虚拟账户初始化
- 买入
- 卖出
- 持仓查询
- 交易记录分页查询
- 账户资产、收益、收益率实时刷新

### 2.5 工程能力

- 统一异常处理
- 基础参数校验
- 单元测试和部分接口回归

## 5. 当前系统形态

当前代码是一个模块化单体应用，不是微服务。

主要模块包括：

- 用户模块
- 鉴权模块
- 行情模块
- 自选股模块
- 模拟交易模块

这些模块都运行在同一个 Spring Boot 进程内，通过 REST API 对外提供服务。

---

## 6. 当前接口范围

### 6.1 认证与用户

- `POST /api/auth/register`
- `POST /api/auth/login`
- `POST /api/auth/logout`
- `GET /api/users/me`
- `PUT /api/users/me`

### 6.2 行情

- `GET /api/market/stocks/search`
- `GET /api/market/stocks/{stockCode}`
- `GET /api/market/stocks/{stockCode}/kline`
- `GET /api/market/stocks/{stockCode}/indicators`

### 6.3 自选股

- `GET /api/watchlist`
- `POST /api/watchlist`
- `DELETE /api/watchlist/{stockCode}`

### 6.4 交易

- `GET /api/trade/account`
- `POST /api/trade/buy`
- `POST /api/trade/sell`
- `GET /api/trade/positions`
- `GET /api/trade/records`

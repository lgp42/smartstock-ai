## 3. 初始化步骤

### 3.1 克隆项目

```bash
git clone <repository-url>
cd smartstock-ai
```

### 3.2 初始化数据库

```bash
mysql -u root -p -e "CREATE DATABASE smartstock_ai DEFAULT CHARACTER SET utf8mb4;"
mysql -u root -p smartstock_ai < doc/sql/init.sql
```

### 3.3 启动 Redis

```bash
redis-server
```

如果你本地 Redis 需要密码，请确认和配置文件一致。

## 4. 配置方式

当前配置文件：`src/main/resources/application.yml`

默认支持环境变量覆盖。

常用变量：

```bash
export SMARTSTOCK_DB_URL='jdbc:mysql://127.0.0.1:3306/smartstock_ai?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai'
export SMARTSTOCK_DB_USERNAME='root'
export SMARTSTOCK_DB_PASSWORD='your-password'
export SMARTSTOCK_REDIS_HOST='127.0.0.1'
export SMARTSTOCK_REDIS_PORT='6379'
export SMARTSTOCK_REDIS_PASSWORD='your-redis-password'
export SMARTSTOCK_JWT_SECRET='your-32-byte-secret'
export SMARTSTOCK_SERVER_PORT='8080'
export SMARTSTOCK_ANALYSIS_BASE_URL='http://146.190.49.37:8000'
export SMARTSTOCK_GEMINI_API_KEY='your-gemini-api-key'
export SMARTSTOCK_GEMINI_MODEL='gemini-3-pro-preview'
```

注意：

- `SMARTSTOCK_JWT_SECRET` 建议至少 32 字节
- 当前没有 `dev/test/prod` 多 profile 体系

## 9. 联调说明

### 9.1 登录流程

1. 调 `POST /api/auth/register`
2. 调 `POST /api/auth/login`
3. 取返回的 `token`
4. 访问受保护接口时加上：

```text
Authorization: Bearer <token>
```

### 9.2 行情联调

当前行情来自东方财富 HTTP 接口，联调时请注意：

- 外部接口偶尔可能慢或波动
- 项目有 Redis 缓存
- K 线接口当前会按 `limit` 截断返回
- 技术指标支持 `macd/kdj/rsi/ma/boll` 和逗号组合

### 9.3 AI 服务联调

当前 Java 应用通过 `SMARTSTOCK_ANALYSIS_BASE_URL` 调用 Python AI 服务。

默认地址：

```text
http://146.190.49.37:8000
```

当前公网健康检查需要关注：

- `GET /api/analysis/health` 由 Java 应用代理检查外部服务
- 如果远端 `:8000` 返回 `502`，优先排查服务器上的 Python AI 容器/进程和反向代理
- 服务器连接资料位于 `/Users/antares2/Downloads/LocalSend/YunUbuntu`，不要在日志或提交中泄露私钥和 passphrase

## 10. 当前已知边界

以下不是 bug，而是当前范围限制：

- WebSocket 是行情快照订阅，不是复杂订阅中心
- 风险预警是实时计算，不是后台主动推送告警系统
- 回测是轻量买入持有测算，不是完整量化平台
- 模拟交易支持轻量限价挂单和撤单，但不是交易所级撮合系统
